# Dataset Download Instructions

This directory is gitignored. Download datasets manually and place them as follows.

## Vision (RGB Surface)

### LoHi-WELD (primary)
- Source: https://github.com/SylvioBlock/LoHi-Weld
- Place in: `raw/vision/lohi_weld/`
- 3,022 GMAW surface images, YOLO + COCO annotations

### Wijaya Kaggle
- Source: https://www.kaggle.com/datasets/sukmaadhiwijaya/welding-defect-object-detection
- Place in: `raw/vision/wijaya_kaggle/`
- ~4,000 images, 6 classes

### FINAL WELDING DATASET
- Source: https://universe.roboflow.com/data-tixsi/final-welding-dataset-qrz4x-cliho
- Place in: `raw/vision/final_welding/`
- 4,900 images, 15 classes

## Geometry (3D)

### Blender renders
- Generated by: `blender/scripts/generate_welds.py`
- Output to: `blender/exports/rgb/` and `blender/exports/depth/`

### abonyilab 3D scanner data
- Source: https://github.com/abonyilab/3D-scanner-data
- Place in: `raw/geometry/abonyilab_3d/`

## Ultrasonic

### Synthetic features
- Generated by: `src/ut/generate_synthetic.py`
- Output to: `raw/ut/synthetic/`

## Class Remapping

Run `src/vision/remap_classes.py` to consolidate all vision datasets into:
```
data/processed/vision/
├── train/
│   ├── porosity/
│   ├── lack_of_fusion/
│   ├── crack/
│   └── no_defect/
├── val/
└── test/
```
